# 🚀 DeployAnyIT

**Plateforme de déploiement automatisé d’applications cloud-native**  
Automatise le cycle de vie complet : gestion du code, build, conteneurisation, déploiement et monitoring — tout depuis une interface simple.

---

## 🔹 Fonctionnalités principales

- **Gestion du code** : Intégration avec GitHub via OAuth2 pour clonage, commit et push.  
- **CI/CD automatisé** : Génération et déploiement automatique de pipelines GitLab CI/CD.  
- **Conteneurisation** : Build d’images Docker avec Paketo Buildpacks (sans Dockerfile).  
- **Déploiement** : Gestion et déploiement sur Kubernetes.  
---

## 🛠️ Technologies utilisées

- **Frontend** : Angular  
- **Backend** : Spring Boot  
- **CI/CD** : GitLab CI/CD  
- **Conteneurs** : Docker & Paketo Buildpacks  
- **Orchestration** : Kubernetes  
- **Auth** : OAuth2 & GitHub & Google
